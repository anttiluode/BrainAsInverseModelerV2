Claim boundary

What this does—and does not—show

Different passive branch dynamics can create distinguishable temporal fingerprints, and an ongoing cable state can retain useful information about a hidden dynamical world. Symmetry destroys source identity. A single soma snapshot destroys most source dimensions. A wrong cable can reproduce its accessible waveform while giving the wrong hidden inputs. Ordinary delay coordinates beat this illustrative cable on the Lorenz benchmark, so the result is a mechanism demonstration, not a cable-superiority claim or a biological validation.
